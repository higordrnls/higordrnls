## Featured Projects

### Distributed Wagering Processor / Tigrinho de Mentirinha

A distributed virtual-wallet transaction processor exploring idempotency, concurrent operations, transactional consistency, immutable ledgers, messaging, and recovery. The same repository includes a playable fictional slot-machine demo with persistent virtual wallets and server-generated results.

The public game uses its own Cloudflare/Neon backend, separate from the NestJS/SQS processing pipeline. No real-money betting.

**Stack:** Bun · TypeScript · NestJS · PostgreSQL · SQS · Docker · Cloudflare · Neon

[Play demo](https://distributed-wagering-processor.pages.dev/) · [Repository](https://github.com/higordrnls/distributed-wagering-processor) · [Architecture case study](https://github.com/higordrnls/distributed-wagering-processor/blob/main/docs/PORTFOLIO_CASE_STUDY.md)

### Agadê — Digital Eyewear Platform

An eyewear brand and digital product concept exploring contemporary design, digital fabrication, circular economy, and product architecture. The live experience is a conceptual catalog prototype, not an operating store; checkout and commercial operations are not live.

**Stack:** React · TypeScript · Vite · Tailwind CSS · Motion

[Explore prototype](https://agade.vercel.app/) · [Repository](https://github.com/higordrnls/agade)
